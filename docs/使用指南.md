# ML Toolbox 使用指南

ML Toolbox 把数据处理、方法比较、训练观测和优化试验组织成可复现的实验过程。软件保存数据集、运行、指标、曲线、checkpoint 和产物；AI 负责选择方法、提出实验和解释结果。

## 常用流程

1. `describe_methods` 了解适合当前任务的方法；
2. `prepare_dataset` 建立可复用的数据处理规格；
3. `run_method` 或 `run_method_batch` 运行方法；
4. `compare_methods` 直接取得对比表；
5. `describe_run`、`describe_training` 和 `checkpoint_detail` 查看结果；
6. 自定义网络使用 `run_custom`，需要时从 checkpoint 续训。

## 数据和比较

训练集、验证集、特征处理和随机种子都会进入运行记录。比较方法时确认数据集、划分、指标方向和资源限制相同。长曲线使用 `tags`、`limit`、`compare` 和 `pick` 选择需要的字段，避免把完整时间序列倒入上下文。

## 长任务

神经网络和自定义程序使用 `submit_run`、`read_job`、`cancel_run`。取消是协作式的；最终状态、run id 和产物引用以任务回执为准。checkpoint 用于恢复训练，不等同于一次新的实验。

## 结果解释

指标、诊断、警告和资源消耗要一起看。一个分数不能单独证明方法优越；数据处理、随机种子、训练预算和早停条件都会影响比较。
