## 二、我要干的事是什么（说清楚任务，免得你对不上）

我在研究里德堡原子阵列。一个"阵列配置"包含：

- **N 个原子**（N 从 6 到 18 不等），每个原子有空间坐标和驱动参数；
- 原子两两之间有**耦合**（这是物理量：有的是实数、有的是复数、有符号）；
- 物理引擎用精确对角化算出这个配置的**基态波函数**：
  2^N 个复数振幅 ψ(σ)，σ 是"哪些原子被激发"的位串。

**我想学的模型**是：给它一个阵列配置，它输出这个配置的波函数分布，
于是我可以**不用再做对角化**就采样、算能量、预测观测量。

我要的模型结构（我自己那套脚本里是这么做的）：

```
N 个原子的图（节点特征 + 两两耦合的边特征）
        ↓ 图神经网络，把 O(N²) 的耦合压成 N 个向量
    N 个原子的序列
        ↓ Transformer 编码器 → 自回归解码器（按空间相邻顺序逐个原子输出）
    ψ_θ(σ) = 模长 × 相位
```

关键点：**输出是复数**（有模长也有相位），不是实数。这是我这套东西和你软件里
现有的神经网络最根本的差别——我要学的态里，波函数有正有负、甚至有连续相位。

**规模**：N ≤ 20，模型约 47 万参数，4500 步，单卡训练几十分钟。
（我这边是 RTX 4050 笔记本显卡。）

## 三、我照着说明书试了一遍，卡在哪

我按 AI 模式的说明，试了三条路，都走不通。把现象写下来，方便你判断。

### 3.1 我想走"表格 + 自定义批次"

说明书说 `Network.forward_step` 可以处理"多输入/特殊批次形状"，我就想用它，
把"每个配置采 64 个位串、pad 到最长、配上 mask"塞进去。

**卡住的现象**：我还没走到 `forward_step`，数据就先过不去了。
我的数据送进去的时候，系统把它当成了普通的特征表——复数振幅被弄成了实数，
变长的位串批次也没有地方放。

### 3.2 我想走"图任务（GNN）"

说明书说 `prepare_dataset` 可以给边表，`Network.forward_graph` 能拿到
`edge_index` / `edge_weight` / `n_nodes`，我就想：原子就是节点、耦合就是边，
这不是天然对口吗。

**卡住的现象**有两个：

1. **边特征只能是一个数**。我的耦合有 6 个分量（V、J 的实部虚部、A 的实部虚部、
   距离），塞不进一个标量权重里。硬压会毁掉物理量，我不敢。
2. **图任务好像只能做"给每个节点打一个标签"**。可我不是这个任务——
   我的一张图就是**一整个训练样本**，我要的输出是"整张图对应的一个概率分布"，
   而不是"每个节点一个类别"。而且它似乎是整张图一次前向，我需要在一次前向里
   对同一个配置的多个采样位串并行计算。

### 3.3 我连"我到底在哪一步失败"都问不出来

这一条是最难受的：上面两处，我拿到的反馈都让我怀疑是自己参数写错了，
来回试了好几轮才确认是**任务形态本身对不上**。
如果软件能在我提交一个它接不住的任务时说一句
"这个任务的数据形态是逐组的、不是逐行的，当前不支持"，我就不用白花时间。

## 四、我想要的操作流程（这是本文的重点）

我希望能像这样用（下面是我理想中的一次完整使用，不是接口设计）：

### 4.1 喂数据

我手上是 HDF5 文件（一个文件里几十到上千个配置，每个配置一组数组：
坐标、耦合、复振幅）。我希望**能直接指给它**，或者说清楚"你希望我转成什么格式我就转"。

需要区分两类东西，我自己清楚：

- 每个配置的**元信息**（N、几何类型、耦合尺度……）——这个像表，一行一个配置；
- 每个配置的**大数组**（2^N 个复振幅、逐原子的特征）——这个不像表。

### 4.2 组装模型

我想要的是：**我给一段定义网络结构的代码，剩下的训练全归你管**——
这一条现在就已经有了，我特别认可，也正是我想要的。我只希望它别限制我：
我的网络要输出复数、要有两条输出支路（模长、相位）、要能自回归解码。

我理解"只写结构、训练交给系统"这条纪律，我也愿意守。
问题只是**我这种结构现在写不出来**。

### 4.3 训练时我想看见什么

这是我最想要这个软件的原因。我现在那套脚本只有 loss 和几个指标，
出了问题只能猜。我希望训练时能看到：

| 我想看的 | 为什么 |
|---|---|
| **损失分成三块**：NLL、相位、保真度，各自一条线 | 现在只有一个总 loss，我分不清是哪块在拖后腿 |
| **保真度 F** 和 **只管模长的保真度 F_amp** 两条线 | 这两个的差就是"相位头赚了多少"，是我的核心诊断量 |
| **不同物理通道分开看** | 我有四个通道（两个实的、一个带符号、一个带连续相位），它们的难度天差地别，混在一起看等于没看 |
| **训练集内 vs 尺寸外推分开看** | N≤12 参与训练、N≥14 没见过，我要盯外推有没有崩 |
| **梯度范数、学习率** | 我在排查"某个通道学不动" |
| **某一块损失占比可以前 N 步关掉** | 我有"先只训模长、再上相位"的做法，需要一个"预热"的表达方式 |

### 4.4 训练完我想要什么

**这一条现在是最卡的。** 训练完了我要做三件事，都拿不到训练好的权重：

1. **拿模型去采样**（4096 个构型），跟精确对角化比速度——
   这是我这套东西**唯一的实用价值证明**。N=18 时模型采样比对角化快 15 倍，
   这个数字我要能自己复现出来。
2. **算变分能量** ⟨ψ_θ|H|ψ_θ⟩，跟精确基态能量比——证明"快"没牺牲"对"。
3. **换个没见过的 N 评估**（尺寸外推）。

现在我能查到训练跑完了、指标是多少，但**拿不到那个模型**，
所以上面三件事一件都做不了。

### 4.5 训练完我还想比

我想把"我的模型"和"经典方法的基线"放在同一份数据上比。
比如用梯度提升树去预测"哪些配置难学"——把每个配置的特征
（纠缠度、符号占比、耦合尺度、N、几何）当输入，把模型的保真度当目标，
看哪些特征真正解释了难度。

这一条我觉得是`compare_methods`天生就该干的，我希望能顺畅地用上。
