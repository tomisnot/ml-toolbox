## 0. 与 ML 契约的映射（兄弟框架速查）

| 概念 | ML 侧（core/contracts.py） | 优化侧（opt/contracts.py） |
|---|---|---|
| 参数声明 | `ParamSpec` | **同一个类**（共享内核；新增 `log` 字段） |
| 参数空间 | `RunConfig.resolve(schema)` | `ParamSpace`（采样/向量化/投影） |
| 可插拔单元 | `MLMethod` + `@register` | `Optimizer` + `opt.registry.@register` |
| 任务对象 | `DataSpec`（数据视图） | `Objective`（黑盒评估） |
| 运行 | `runner.run_one -> RunRecord` | `runner.optimize -> OptRecord` |
| 结果 | `MLResult.artifacts` | `OptRecord.history`（DataFrame 评估轨迹） |
| 持久化 | `runs/<id>/{record.json, artifacts.npz}` | `runs/opt-<...>/{opt_record.json, history.csv}` |
| 检视页 | `PageSpec` + `inspector.PAGE_BUILDERS` | **同一套**（`Optimizer.inspect_pages`） |

## 1. ParamSpace（`opt/contracts.py`）

由 `list[ParamSpec]` 构成。维度规则：

- `number`（有界）/ `int` / `select` / `bool` → 各占 1 寻优维；
- `number` 无界（min/max 缺省）与 `text` → **不参与寻优**，按默认值固定透传
  （优化器只能在有界域工作；如 `torch_mlp.hidden="64,32"` 这类结构参数）；
- `log=True` → 对数尺度均匀采样（lr/正则强度类）。

内部坐标统一 `[0,1]^dim`：`to_vector(dict) -> ndarray`、`from_vector(ndarray) -> dict`
（自动 clip 回界内，越界候选安全）。`sample(rng)` 先验均匀采样；
`grid_points(n)` 网格（基线用，runner 截断防爆）。

## 2. Objective（黑盒）

```python
class MyObj(Objective):
    space = ParamSpace([...])
    noise = False          # 含噪评估（仿真标定）→ 提示需要重复评估
    minimize = True        # 最大化目标用 False，runner 统一取负

    def evaluate(self, params: dict) -> float: ...
```

- 失败处理（P10）：`evaluate` 抛异常或返回非有限值 → runner 记
  `status='failed'`、分数 `+inf` 喂回优化器，**循环不中断**；
- `make_objective(fn, space, name=...)`：lambda 快速包装（数模标定、合成函数、
  AutoTuner 都用它）。

## 3. Optimizer（增量契约）

```python
@register
class MyOpt(Optimizer):
    name = "my_opt"; family = "bo"        # baseline|bo|evo|schedule|local
    batch = False                          # True = ask 返回一代 list[dict]
    param_schema = [ParamSpec(...)]        # 优化器自身超参（复用 ParamSpec）

    def ask(self): ...                     # -> dict | list[dict]
    def tell(self, params, score, status): ...
```

- 生命周期：runner 先调 `setup(space, seed, cfg, budget)`，再循环 ask/tell；
- 内部信念（GP 后验 / CMA 分布 / 种群）完全自持，框架不感知；
- `inspect_pages(record)` 返回 `core.PageSpec` 列表——**与 ML 共用同一 UI 装配器**，
  新页类型仍走 `inspector.register_page_builder(kind, builder)`。

## 4. Budget 与 runner

```python
Budget(n_evals=50, time_limit=inf, stall=0)   # 三者先到先停
optimize(objective, optimizer, budget, cfg=None, seed=42,
         on_eval=None, should_stop=None) -> OptRecord
```

- `on_eval(record, i)`：每次评估后回调 = **UI 直播接入点**（P13），
  record.history 截至当前完整可用；
- `should_stop()`：外部中止（UI"停止"按钮），在两次评估之间检查；
- `compare_records(records)`：多优化器横向对比表（G4 遍历的回报）。

## 5. OptRecord（数据资产）

`history` DataFrame 列 = 各寻优参数 + `score, status, ts, best_so_far`
（`best_so_far` 单调不增，收敛曲线直接画）。

- `to_dataset()` → `core.Dataset`（参数为 X、分数为 y）= **接缝3 物理载体**：
  评估历史回流 ML 做响应面/敏感性分析；
- 持久化：`opt/persistence.save_record` 写 `opt_record.json + history.csv`；
  run_id 前缀 `opt-` 与 ML 记录共存于 `runs/` 且互不混淆
  （两侧 `list_records` 各自过滤）。

## 6. 已注册优化器

| name | family | 引擎 | 说明 |
|---|---|---|---|
| random_search | baseline | 自研 | 参照物（对标 ML 的 dummy） |
| grid_search | baseline | 自研 | 网格 + 预算内抽稀 |
| gp_bo | bo | 自研（复用 sklearn GPR） | GP-EI/UCB/PI，连续/混合空间小预算；`surrogate_1d()` 供代理面页 |
| cma_es | evo | 自研 | 协方差自适应进化策略，batch 种群式；`distribution()` 供演化动画 |
| nsga_ii | evo | 自研 | 多目标：非支配排序+拥挤距离+SBX，`OptRecord.pareto` 前沿 |
| nelder_mead | local | 自研 | 单纯形法，光滑问题局部精修 |
| tpe | bo | 适配 optuna | 树密度估计，混合/类别空间强项 |
| asha | schedule | 适配 optuna | Successive Halving 早停（调 ML 超参省预算） |

采集函数在 `opt/engines/acquisition.py`（EI 闭式解 + 正态 cdf/pdf 用 math.erf
自实现，零 scipy.optimize 依赖）。optuna 为可选依赖，未装则 tpe/asha 不注册。

### 三接缝桥（`opt/bridges.py`，阶段4）

- **接缝1（ML→调参）**：GP-BO 内部代理直接复用 sklearn `GaussianProcessRegressor`
  （`purpose=surrogate` 的兑现，无额外代码）。
- **接缝2（调参→ML）**：`AutoTunerObjective` + `autotune(method, 数据, ...)`
  把"方法在数据上的 CV 主指标"包成黑盒，优化器调 `RunConfig.overrides`。
  **数据来源不绑定 ML 工作区**（见下"数据源"），ML 内部数据集只是来源之一。
- **接缝3（调参历史→ML）**：`OptRecord.to_dataset()`（参数为 X、分数为 y）+
  `response_surface(record, method)` 拟合响应面回归（数模敏感性分析）。

### 数据源与外部程序接入（`opt/sources.py` / `opt/process.py`）

"接入正在运行的程序"有两个正交接入点，别混成一个：

- **数据侧**（`DataSource`，程序持续产数、调参消费它）：
  `FileSource(path, target, reload_each=True)`——外部程序只管往 csv/parquet 写，
  mtime 变化才重读（廉价轮询语义）；`SpecSource`（ML 内部数据集薄包装）；
  `ArraySource`（裸数组兼容层）。`AutoTunerObjective` 三种入口都接受：
  `(name, X, y)` / `(name, source)` / `(name, DataSpec|Dataset)`。
- **评估侧**（`ProcessObjective`，程序本身就是黑盒）：
  参数注入命令模板（`{key}` 占位、`{params_file}` 写 json 临时文件）→ 子进程 →
  stdout 正则或结果 json 解析分数；非零退出码/超时/解析不到 = failed（P10）。
  子进程输出 utf-8 优先、GBK 兜底（Windows 中文管道坑，pitfalls P1）。

**硬约束黑盒**（模拟软件主动拒绝不可行输入）：
- `Objective.has_constraints` + `is_constraint_error(exc)`：区分"约束违反"
  （有用信息，runner 记 `status='infeasible'`）与"程序崩溃"（噪声，failed）；
- `ProcessObjective(constraint_signal=..., on_infeasible=...)`：
  `censor`（默认，infeasible 喂 cEI 分类器）/ `penalize`（自适应惩罚分 =
  历史最差可行分×penalty_mult，全量点喂 GP）/ `raise`（当普通失败）；
- GP-BO `cfg["constrain"]=True` 开 cEI（采集 = EI × P(可行)，
  可行域由第二个 GP 分类器建模）；
- **策略选择（彩排实测，pitfalls P2/P3）**：薄可行带用 `penalize`（最强）；
  可行占比中等用 censor+cEI；裸 censored 会让 GP-BO 静默退化成随机。

**ParamSpace 有界规则**：`text` 与"min/max 缺失的 number/int"（如 knn 的
`leaf_size`）无法归一化 -> 固定透传默认值，只寻优有界参数。

### 验收基准

## 7. 铁律继承

- 入口顺序：`opt.registry.load_builtin()` 同样必须**先于任何 PyQt5 import**
  （GP-BO 经 sklearn/GPR，OpenMP 教训 L1 适用）；
- 方法层零 Qt（P8）：`opt/` 全包不 import PyQt5；
- 可复现（P11）：`seed + 预算` 决定轨迹；`history.csv` 可完整重放。
